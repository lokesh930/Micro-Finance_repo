This repository marks the first step in our micro-finance startup's transition from Subversion (SVN) to Git for version control. As part of our broader mission to empower and create financial opportunities for low-income individuals, we are embracing open source practices to foster transparency, collaboration, and community-driven innovation.

The project hosts a simple script to calculate Simple Interest, serving as a foundational example for future financial tools we aim to build and share. This initiative is not only technical—it reflects our commitment to open development, community inclusion, and best practices in software engineering.

By publishing this code on GitHub under the Apache License 2.0, along with a clear Code of Conduct and Contribution Guidelines.

A calculator that calculates simple interest given principal, annual rate of interest and time period in years.
Input:
   p, principal amount
   t, time period in years
   r, annual rate of interest
Output
   simple interest = p*t*r
